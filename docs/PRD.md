# 时予 Timely — 产品需求（v1.0）

> 起草：GLM-5.3，2026-10-24。范围以 remind_me（Flutter，2024）**实际已实现**的功能为基线，叠加修复与收敛。
> 旧 PRD 原文：`D:\Projects\Android\remind_me\docs\PRD.md`（仅作历史参考，其中大量规划未实现且不在本期范围）。

## 1. 产品定位

倒数日 / 正数日 App：记录期待的日期（倒数）和纪念的日期（正数），辅以日历、倒计时、秒表。
极简风格，蓝色主色调，中英双语，单机无网络功能。

- 中文名：时予　英文名：Timely　包名：`com.airlur.timely`

## 2. v1.0 功能范围

### 2.1 倒数日 / 正数日（核心）

- 事件增删改查；标题 ≤ 20 字
- 目标日期 + 时间；支持**农历日期**录入（存农历，显示公历对应日）
- 置顶：最多 1 个，置顶事件占据列表顶部 banner 大卡片
- 分类：1 级分类，最多 8 个（名称 + 可选图标），列表可按分类筛选
- 排序：按创建时间 / 按日期远近 / 手动拖拽，三选一
- 显示单位：天 / 周 / 月 / 年，双击卡片切换；年、月单位显示组合值（如「2 年 3 个月」）
- 含首日开关：正数日按「第 N 天」计数
- 卡片背景样式：**纯色 20 预设 + 渐变 23 预设**（色板见 DESIGN.md，完整保留自旧版）
- 列表交互：单击进详情；右滑出操作（置顶/编辑/删除）；长按拖拽排序
- 空状态引导页
- 重复规则：不重复 / 每天 / 每周 / 每月 / 每年 / 自定义（间隔 + 单位 + 指定星期 / 指定月内日期 + 结束日期）；到期后自动滚到下一次

### 2.2 提醒通知（本次重构的重点修复项）

- 每个事件**多个提醒时间点**（最多 5 个），以「提前量」表达：5 分钟 ~ 7 天
- 通知形式：横幅 + 锁屏 + 声音 + 震动（走系统通知渠道）
- 首次创建带提醒的事件时请求通知权限；拒绝后可在设置里引导开启
- 设置页提供「测试通知」（即时 + 延迟 10 秒）
- **可靠性要求（验收标准）**：重启手机后提醒不丢；App 被划掉后照常触发；重复事件触发后自动排下一次；时区/时间变更后重算

### 2.3 日历

- 月视图网格，农历与事件角标
- 点击日期显示当日事件列表；可从当日快速新建

### 2.4 时间页

- 倒计时：时分秒设置（上限 99:59:59）、启动/暂停/重置、到点声音+震动+通知、常用时长快捷键
- 秒表：启动/暂停/计次/重置，计次列表显示每圈与累计，最快/最慢圈标记

### 2.5 设置

- 语言：跟随系统 / 中文 / 英文
- 主题：跟随系统 / 亮 / 暗
- 通知设置入口 + 权限状态显示 + 测试通知
- 关于：版本、开源地址

## 3. 明确不做（v1.0）

桌面小组件（留 v1.1）、锁屏小组件、分享模板、云同步、多设备、会员/付费、图片背景（v1.1 再议）、动画背景、时间线记录、标签、系统日历读写、邮件/短信提醒、数据统计图表、番茄钟。

## 4. 相对 remind_me 的修复清单

| 旧版问题 | v1.0 方案 |
|---|---|
| 精确提醒依赖 SCHEDULE_EXACT_ALARM 特殊授权，用户不开就不准时 | 改用 `AlarmManager.setAlarmClock`，闹钟级无需特殊授权 |
| 进程被杀/重启后提醒丢失，无兜底 | BootReceiver + 包更新重排 + 启动重排，见 ARCHITECTURE.md |
| 时区硬编码 Asia/Shanghai | 跟随系统时区（java.time） |
| 通知 ID 用 UUID.hashCode 可能碰撞 | 自增 Int 主键 × 10 + 槽位号，稳定唯一 |
| 每事件仅 1 个提醒点 | 最多 5 个提前量槽位 |
| Manifest 申请悬浮窗/电池优化/双精确闹钟权限吓人 | 全部移除，只留必要权限 |
